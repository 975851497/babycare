# Scripts 目录

这个目录包含项目的批处理和工具脚本。

## 🚀 批量导入脚本

### `run_batch_import.py`

批量导入 `data/` 目录下的所有文件到知识库。

#### 使用方法

```bash
# 在项目根目录执行
python scripts/run_batch_import.py
```

#### 功能说明

1. **自动扫描**：递归扫描 `data/` 目录下的所有文件
2. **格式过滤**：只处理 `.md`, `.txt`, `.pdf` 文件
3. **批量处理**：逐个调用 Import 流程处理文件
4. **实时日志**：显示当前处理进度和状态
5. **异常处理**：单个文件失败不影响其他文件的处理
6. **结果统计**：完成后显示成功/失败统计

#### 输出示例

```
============================================================
🚀 开始批量导入育儿知识库
============================================================
📁 数据目录: D:\ProjectLlists\babycare\data
📄 支持格式: .md, .txt, .pdf
============================================================

🔍 扫描文件...
✅ 找到 25 个文件

[1/25] 处理: 沟通话术/亲子冲突降温沟通话术.md ✅ 成功
[2/25] 处理: 沟通话术/餐桌冲突与挑食沟通话术.md ✅ 成功
...

============================================================
📊 批量导入完成！
============================================================
总计: 25 个文件
✅ 成功: 24 个
❌ 失败: 1 个
============================================================
```

#### 注意事项

- 确保 `.env` 文件配置正确
- 确保向量数据库服务已启动（如果使用）
- PDF 文件需要 MinerU 工具支持
- 处理大量文件时可能需要较长时间

## 🧪 全流程测试脚本

### `test_full_flow.py`

测试 Import 和 Query 流程的端到端功能，验证系统完整性。

#### 使用方法

```bash
# 在项目根目录执行
python scripts/test_full_flow.py
```

#### 功能说明

1. **Import 流程测试**：
   - 自动选择 3 个测试文件进行导入
   - 验证文档解析、文本切分、向量生成、向量存储功能
   - 显示每个步骤的执行结果

2. **Query 流程测试**：
   - 使用 3 个典型的育儿问题进行查询测试
   - 验证知识检索、答案生成功能
   - 展示"育儿专家"风格的回答

3. **端到端验证**：
   - 测试完整的数据流：导入 → 检索 → 回答
   - 检查各模块之间的协作是否正常
   - 提供详细的测试报告

#### 测试文件

脚本会自动使用 `data/沟通话术/` 目录下的文件：
- 餐桌冲突与挑食沟通话术.md
- 亲子冲突降温沟通话术.md
- 手足冲突调解沟通话术.md

#### 测试问题

- "宝宝挑食怎么办？"
- "孩子之间打架如何处理？"
- "家长情绪失控怎么沟通？"
